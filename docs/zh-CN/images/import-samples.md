# UI 文档导入样例

[English](../../en-US/images/import-samples.md)

UI 模块参考和资产预览截图共用以下输入文件。它们用于说明 STEP、STL、INP 导入界面，不是可独立运行的优化算例。

| 文件 | 用途 |
|---|---|
| [PartDesignExample-Body.step](../../../scripts/docs/assets/PartDesignExample-Body.step) | CADPart 的 STEP 导入与预览示例。 |
| [reference-boundary.stl](../../../scripts/docs/assets/reference-boundary.stl) | 固定 STL 曲面预览示例。 |
| [reference-box.inp](../../../scripts/docs/assets/reference-box.inp) | INPPart 网格、集合和材料读取示例。 |

引用这些资产的文档和 UI 资源清单均使用相对路径。
