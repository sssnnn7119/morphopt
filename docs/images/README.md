# UI 文档配图

- `ui/`：UI 快速开始截图。
- `ui-reference/`：模块与接口参考截图、说明图与接口清单。

两组图片均按模块分目录，文件名称采用描述内容的英文小写词组，单词以连字符连接，不使用编号前缀。

| 分类目录 | 内容 |
|---|---|
| geometry | 部件、边界曲面、实例与导入 |
| cad | CAD 建模操作 |
| loads | 载荷、工况、连接、边界与接触 |
| materials | 材料分配与本构模型 |
| objectives | 目标、指标、Jacobian 与数据模板 |
| solver | 求解任务与运行配置 |
| updaters | 形状、材料更新及其约束 |
| custom-code | 辅助代码、自定义类与生成代码 |
| optimization | 优化历史、设计、变形与运行进度 |
| finite-element | 事后有限元、场值、重算与导出 |
| workspace | 主界面通用菜单 |
| diagrams | 对象关系和计算流程说明图 |
